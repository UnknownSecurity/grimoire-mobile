# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest 0.x release | Yes |
| Older development builds | No |

Security fixes are made against the latest supported release and `main`.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting form](https://github.com/UnknownSecurity/grimoire-mobile/security/advisories/new)
and include:

- The affected version and component
- Reproduction steps or a minimal proof of concept
- The expected impact and any known mitigations
- Whether the issue has been disclosed elsewhere

Maintainers aim to acknowledge reports within seven days and will provide
updates as investigation progresses. Please allow time for a fix and release
before public disclosure.

## Safe downloads

Only download Grimoire Exodus from the
[official GitHub Releases page](https://github.com/UnknownSecurity/grimoire-mobile/releases).
Unofficial mirrors, repacks, and installers are not verified and may contain
malware, credential stealers, cryptocurrency miners, or modified binaries.

The HARMAN AIR runtime exists only for the official AQW client loaded by this
application. Do not use the app or its runtime to open untrusted SWF content.
