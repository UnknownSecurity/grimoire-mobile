# Grimoire Exodus Mobile v1.0.0

The first public Android release of Grimoire Exodus Mobile.

> **Known issues:** This release is currently buggy. Some features and legacy
> GBot behaviors may not work correctly yet. These issues will be addressed in
> upcoming releases.

## Highlights

- HARMAN AIR AQW client with the Grimoire overlay.
- Mobile Bot Manager with legacy GBot loading, editing, looping, and expanded
  command support.
- Runner background controls and status notifications.
- Packet, Bank, Tools, and Options access from the overlay.
- Draggable Ciel control and smoother overlay transitions.
