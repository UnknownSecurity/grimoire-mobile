# Grimoire Exodus Mobile v1.1.0

This pre-release focuses on Bot Manager parity and faster in-game control.

## Highlights

- Desktop-style Bot Manager fields, command editing, active-action tracking,
  paging, looping, and broader legacy GBot compatibility.
- Expandable, draggable Ciel launcher with separate Grimoire and Room overlays.
- Room cell, pad, and position inspection with known-value selection and
  bridge-backed movement.
- Above-keyboard typing preview across AQW and Grimoire fields, with passwords
  masked.
- ARM64 production packaging plus an explicit x86 emulator debug target.
- Independent mobile release feed and version detection.

> **Pre-release:** Mobile GBot coverage and live game behavior are still being
> expanded. Keep a known-good bot and monitor the active action list while
> testing this build.
